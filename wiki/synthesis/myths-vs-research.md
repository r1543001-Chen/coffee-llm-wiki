# 常識 vs. 研究結果

**這頁回答的問題**：關於沖咖啡的常見說法，哪些有研究支持、哪些被挑戰、哪些還沒有答案？

（由 query 產生並存回 wiki，2026-11-24）

| 常見說法 | wiki 中的研究怎麼說 | 判定 |
|---|---|---|
| 水溫一定要 92–96°C | 濃度與萃取率固定時，87–93°C 的滴濾咖啡嚐不出差別。[來源: batali-2020] | 被挑戰（限滴濾、87–93°C） |
| 有一個人人適用的「理想」沖煮範圍 | 消費者至少分成兩群，喜好位置不同；「理想」是平均出來的假象。[來源: guinard-2023] | 被挑戰（樣本為北加州年輕成人） |
| 萃取率越高越苦 | 一項實驗中苦味只跟濃度有關；另一項跨烘焙度的研究則顯示兩者都有關。[來源: batali-2020] | 未定論 |
| 萃取不足會偏酸 | 低萃取率時酸、柑橘、莓果風味最強。[來源: batali-2020] | 有支持 |
| 不同產地的豆子要用不同的研磨刻度 | 四支不同產地與處理法的豆子，粒徑分布幾乎相同。[來源: uman-2016] | 被挑戰（限淺中焙、粒徑層面） |
| 磨豆機刻度固定，粉就會一樣 | 豆子與刀盤的溫度會改變粒徑分布。[來源: uman-2016] | 被挑戰 |
| 磨越細、萃取越快 | 細研磨的顆粒內擴散時間遠短於粗研磨。[來源: moroney-2016] | 有支持 |
| 富含鎂的水能萃出更多風味 | 計算顯示鎂與咖啡成分結合最強；但實驗發現有機酸的萃取與鎂、鈣無關。其他成分未經驗證。[來源: hendon-2014] [來源: bratthall-2024] | 來源互相牴觸 |
| 軟水器（以鈉換鈣）對咖啡有益 | 計算顯示鈉與咖啡成分結合很弱，只能防水垢。[來源: hendon-2014] | 被挑戰（僅計算，無實驗） |
| 泡越久，溶出越多 | 是，但先快後慢；可萃取的總量有上限（約 28–32%）。[來源: moroney-2016] | 有支持，附但書 |

## 從這張表看出的共同模式 (推論)

1. **旋鈕與結果要分開看**。研磨、水溫、時間、粉水比是手上能轉的旋鈕；濃度與萃取率是轉完之後的結果。研究顯示風味主要跟著結果走，不同的旋鈕組合只要達到同一個結果，風味就接近。
2. **「被挑戰」不等於「被推翻」**。每項研究都有適用範圍，表中第三欄的括號就是它的邊界。
3. **水質是證據最薄弱的一塊**。只有一篇計算、一篇實驗，結論相反，而且兩篇都沒有處理碳酸氫根，也都沒有請人試喝。
